# GALAXY ZERO

A browser-based 3D sci-fi exploration game. Explore the mysterious surface of Elysium-4, avoid unknown drones, and recover all six energy shards.

## Current prototype

- 3D planetary surface with a starfield and distant ringed planet
- Third-person astronaut character
- Keyboard movement (WASD or arrow keys)
- Six collectible energy shards and live mission progress
- Alien drone props, suit status HUD, local radar and pause menu
- Responsive sci-fi interface

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Controls

- W / A / S / D or arrow keys: move
- P or Escape: pause / resume

## Tech stack

React, Vite, Three.js, React Three Fiber, Drei and Lucide.
